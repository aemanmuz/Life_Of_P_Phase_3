# LIFE OF P — Phase 3 · A Living Valley (v0.3.0)

A **playable 2D top-down open-world Action RPG / life-sim prototype**, built with HTML5 Canvas, CSS3 and Vanilla ES modules. Phase 3 extends **Phase 2 combat, enemies, loot and exploration** with growing seasons, a 48-plot farm, crafting, village NPCs, social relationships, an estate, marriage and a simplified generational inheritance loop.

All graphics are generated by Canvas; no external images, audio or database connection required. The playable world and its characters are original placeholders rather than copyrighted franchise characters.

## Play in VS Code or GitHub Pages

1. Extract the entire `life-of-p/` folder. Open it in **Visual Studio Code**.
2. Right-click **`index.html`** → **Open with Live Server**. Alternatively deploy the directory's contents to the root of your GitHub Pages repository.
3. In Chrome, visit the local server address (e.g. `http://127.0.0.1:5500/`) or your published GitHub Pages URL.
4. Select **Begin Your Journey** or **Continue Journey**.
5. Press **L** for the Life-Sim Guide, containing step-by-step directions for the new features.

The checked-in `js/offline.bundle.js` also lets you double-click `index.html` and play using `file://`. It is generated from the same modules. After editing a JS module, run `npm run build:offline` to rebuild the offline fallback. GitHub Pages and Live Server load the ES modules directly and do not need this rebuild.

## Phase 3 walkthrough (fast first harvest)

1. From the village starting point, head **southwest**. The farm is visible as a rectangular brown field at map coordinates **X 35–42, Y 41–46**. You begin with **four Ash Turnip Seeds**.
2. Stand close to any square of soil, press **E**, and select **Till Soil**. Then **Plant Ash Turnip** and **Water**. All plot actions happen from the same popup.
3. Visit the **Fallow Cottage** (west of the village, marked HOME), or the **campfire** (near the center). Press **E**, then **Sleep / Rest Until Morning**. You can repeat to advance calendar days.
4. After **two growing days**, return to the planted plot and press **E → Harvest**. The crop enters your inventory.
5. Speak with **Bram** (the seed merchant) who stands near the village/farm during the day. Buy seasonal seeds for 4 gold each, or sell harvested produce. These actions work only while near Bram.
6. Gather **Moonmint Herbs** from the HERBS patch east of the farm **once per day**. Defeat enemies for **Ash Fragments**, then use **C** or the forge to craft Ember Flasks or food.
7. Find **Mira** (near the fields in daytime) and **Rowan** (near the crossroads). Speak once/day and offer crops or herbs as gifts once/day. Reach 70 friendship; claim the cottage for **50 gold** to propose.
8. After marrying and spending **two days** together, visit the cottage to welcome an heir named **Eira** or **Ari**. When seven days pass, retire at the cottage to continue as the grown child. Inventory, gold, farmland, completed milestones and equipment are inherited. The new generation begins with full health/stamina and friendship reset.

## World calendar and farming

- 7 days per season: **Spring → Summer → Autumn → Winter** (28 days per year).
- Crop timings count **watered nights**: turnips 2, wheat 3, pumpkin 4, frostroot 3.
- Seasonal restrictions: turnips (Spring/Autumn), wheat (Spring/Summer), pumpkin (Summer/Autumn), frostroot (Winter).
- Rain can water crops automatically. Seasons that cannot grow a crop pause its growth rather than killing it. Crops do not spoil in this prototype.
- NPC daily schedules vary between morning, afternoon, evening and night. The map marks their positions.
- The simplified heir inheritance loop is a proof of concept: it does not yet include childhood gameplay, ancestry traits, full NPC household AI or a permadeath toggle.

## Saved games

Progress is saved automatically every ~30 seconds, from the pause menu, and after a generation change. All data is stored in this **browser's `localStorage`**, not a remote database. Continuing on the same browser and origin imports existing **Phase 1 and Phase 2 saves** automatically. Phase 3 upgrades those saves to version 3, while preserving combat gear, gold, enemies and quest progress. Uploading changes to GitHub does *not* transfer localStorage saves between different browser origins/devices.

To safely deploy: **keep the same GitHub Pages repository and site URL**, extract the archive and replace the old files. The HTML entry point must remain at the repository root. Back up custom edits before overwriting anything. Use **Ctrl+Shift+R** after publishing to bypass stale cached JavaScript/CSS.
